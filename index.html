Backup completo
Exportar backup
Baixa um único arquivo .json com todos os seus artigos, links, anotações, tema atual e todos os anexos (fotos, vídeos, PDFs) incorporados em base64. Guarde esse arquivo no Google Drive, OneDrive, pen drive ou junto do código no Git.

Carregue um arquivo de backup gerado anteriormente. Você poderá escolher se quer substituir os dados atuais ou mesclar com os existentes.
Dados no navegador
Apagar todos os dados
Remove permanentemente artigos, links, anotações e anexos deste navegador. Ação irreversível — faça um backup antes.
Sobre o armazenamento

Este site não usa servidor nem banco de dados externo. Os dados são guardados no próprio navegador:

  • localStorage — artigos, links e anotações (dados de texto). Limite ~5 MB.
  • IndexedDB — anexos (fotos, vídeos, PDFs). Limite ~50% do espaço livre do disco.
  • localStorage — também guarda a preferência de tema (claro/escuro).

Atenção: limpar "dados de sites" ou "cache" do navegador apaga tudo. Abrir o site por uma URL diferente (ex.: file:/// vs https://) também cria um espaço de dados separado. Use o backup para migrar entre ambientes.
